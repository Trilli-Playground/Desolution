# Working preferences for this repo

- The expected output of any task here is a **live, working site** at
  `desolution-seven.vercel.app` (or whichever domain is current) — not just
  code merged to `main`. If getting there needs several steps (DB
  migrations, env vars, a manual trigger, a PR merge), do all of them
  yourself as far as you're able to.
- Anything that genuinely can't be done from this session (setting Vercel
  environment variables, rotating a third-party API key, anything needing
  a login you don't have) must be called out as a **clearly separated,
  unmissable instruction to the user** — not folded into a paragraph. Use a
  short numbered list headed something like "Was du selbst tun musst" so it
  can't be missed.
